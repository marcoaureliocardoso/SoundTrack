# SoundTrack 1.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publicar o SoundTrack Android `1.1.0+4` como tag e GitHub Release
`v1.1.0`, usando um APK assinado, validado e acompanhado de SHA-256.

**Architecture:** A publicação promove o refinamento visual já mesclado sem
alterar comportamento ou o esquema JSON. Metadados e documentação são
atualizados em uma PR; o artefato é gerado e validado a partir do commit
mesclado e somente então a tag e a Release são publicadas.

**Tech Stack:** Flutter, Dart, Android/Gradle, Git, GitHub CLI e ADB.

## Global Constraints

- Application ID permanece `br.com.marcocardoso.soundtrack`.
- Versão Flutter/Android: `1.1.0+4`.
- Tag e GitHub Release: `v1.1.0`.
- `schemaVersion` das exportações permanece `1`.
- O mesmo keystore oficial deve assinar o APK.
- Nenhuma senha, keystore ou `android/key.properties` entra no Git ou na
  Release.
- O APK publicado deve ser exatamente o artefato validado.
