# Documentos de desenvolvimento

O diretório `specs/` contém decisões de produto e comportamento aprovadas. O
diretório `plans/` contém registros históricos de como uma mudança foi ou será
executada; passos e exemplos antigos podem permanecer desmarcados ou descrever
um estado posteriormente superado.

Em caso de divergência, use nesta ordem:

1. documentação canônica atual em `docs/design/`, `docs/release/` e `docs/qa/`;
2. especificação aprovada mais recente em `specs/`;
3. planos em `plans/` apenas como histórico de implementação.

Planos não substituem README, changelog, política de release nem checklist de
aceitação.
